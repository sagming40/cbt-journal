# 0007. 배포는 Vultr 서울, 도메인은 Cloudflare에서 산다

- 상태: 채택
- 날짜: 2026-10-30

## 맥락
- 붙잡기 화면(체크인 · 사고 기록 1 ~ 3단계)은 휴대폰에서 생각이 떠오른 순간에 연다. **앱을 처음 여는 속도**가 이 앱의 핵심 순간이다(REQUIREMENTS C1 "10초").
- 같은 사용자의 다른 프로젝트(cosmic-watch · material-dict)는 AWS 새 가입 방식 "프로젝트" 계정에서 막혀 있다: 조직 SCP로 **리전이 시드니로 고정**, Route 53 도메인 등록 실패, 가입이 덜 끝난 예전 일반 계정 때문에 신규 혜택 문제 → AWS Support 케이스(2026-10-28) 답 대기 중(이틀째 미할당).
- 집 PC에서 잰 왕복 시간(2026-10-30, `curl`로 AWS EC2 엔드포인트, 5회 중 예열 제외):

  | | 왕복 1번 (TCP 연결) | 새 연결의 첫 응답 (연결 + TLS + 요청) |
  |---|---|---|
  | 시드니 | 약 0.23초 | 약 0.7초 |
  | 서울 | 약 0.024초 | 약 0.064초 |

  시드니면 앱을 처음 열 때 1 ~ 1.5초, 버튼 하나에 0.25초 정도가 된다. 열린 뒤 조작은 참을 만하지만 처음 여는 순간이 눈에 띈다. (예전 문서의 "0.13초"는 잰 값이 아니었다.)

## 결정
1. **서버: Vultr 서울**, Shared CPU 가장 작은 사양(메모리 1GB, 월 $5 안팎 — 만들 때 화면 값으로 확정). 운영체제 Ubuntu 24.04 LTS. 앱(실행 파일 하나) + Postgres · Valkey(compose) + Caddy가 한 대에 들어간다.
2. **도메인: `sagming.com`을 Cloudflare Registrar에서** 샀다(2026-10-30, 연 $10.46, 자동 갱신, 만료 2027-10-30). 이 앱 주소는 **`cbt.sagming.com`**. 다른 프로젝트도 하위 주소로 같이 쓴다.
3. **Cloudflare는 DNS만 쓴다(회색 구름 · DNS only).** 주황 구름(프록시)을 켜면 Cloudflare가 HTTPS를 풀어 통신 내용을 볼 수 있다 — 감정 기록 앱이라 쓰지 않는다(REQUIREMENTS 5.1). 요금제는 Free.
4. **HTTPS는 서버의 Caddy가 Let's Encrypt로** 받고 갱신한다. 앱은 `127.0.0.1:8080`에만 열고, `TRUSTED_PROXIES`는 Caddy(127.0.0.1)만.
5. 서버 방화벽은 22 · 80 · 443만. SSH는 키로만(비밀번호 로그인 끔). DB · Valkey 포트는 `127.0.0.1`에만 묶는다(Docker가 방화벽을 우회하므로 compose 포트 표기로 막는다).

## 검토한 대안
| 대안 | 탈락 이유 |
|---|---|
| AWS Lightsail 시드니 (프로젝트 계정) | 지출 한도 $30 강제 상한 · 크레딧 $120이 장점. 하지만 처음 여는 속도가 느리고(위 측정), 크레딧 · 한도를 다른 두 프로젝트와 나눠 쓴다 — 한도에 닿으면 세 서버가 다 멈춘다 |
| AWS 서울 (일반 계정) | Support 답에 달려 있고 그동안 아무것도 못 한다. 크레딧도 없다 |
| Oracle Always Free 서울 | 무료지만 7일 동안 사용량이 낮으면 회수하는 규칙이 있어, 대부분 쉬는 이 앱과 맞지 않는다. 네트워크 설정이 두 겹 |
| Cloudflare 프록시로 시드니 속도 보완 | 통신 내용을 Cloudflare가 풀어 본다(위 3) |

## 감수할 것
- **강제 지출 상한이 없다.** 대신 정액제(서버 한 대 월 고정, 트래픽 포함)라 요금이 튀기 어렵다. Vultr는 서버를 **정지(Stop)해도 요금이 나간다 — 멈추려면 삭제(Destroy)**.
- 가입 크레딧 $250은 **2026-11-30에 만료**된다. 그 전까지 테스트 서버를 정리하고, 12월부터는 서버 한 대 값이 카드로 나간다.
- 나중에 옮기기는 쉽다: 백업 → 새 서버 복원 → DNS 한 줄만 바꾼다.
- 데이터는 한국(서울)에 있다. 공개(M8) 때 개인정보 처리 방침에 위탁(Vultr) 사실을 적는다.
