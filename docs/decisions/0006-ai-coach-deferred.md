# 0006. AI 코치는 핵심 기능 뒤 옵트인으로 보류한다

- 상태: 채택
- 날짜: 2026-10-29

## 맥락
- 아이디어: 자동 사고를 쓰면 AI가 섞인 인지 왜곡을 힌트로 주고, 반박을 돕는 소크라테스식 질문을 던진다.
- 감정 기록은 매우 민감한 정보다. 기능을 켜면 기록 내용이 외부 LLM API로 나간다.

## 결정
- 핵심 기능(체크인 · 사고 기록 · 대시보드 · 리마인더)을 다 만든 **뒤**에 추가한다. 요구사항에는 자리만 둔다.
- 넣을 때는 **옵트인**(사용자가 켜야 동작), 사용자별 호출 한도(Valkey), 큐에서 생성하는 구조로 한다.
- 지금 스택에는 LLM 관련 항목을 넣지 않는다. 제공자 · 개인정보 처리 방식은 그때 새 결정 기록으로 정한다.

## 검토한 대안
- **처음부터 포함**: 제공자와 개인정보 정책을 지금 정해야 해서 범위가 커진다.
- **아예 제외**: 민감 정보가 밖으로 나갈 일은 없어지지만, 연습 도구로서 쓸모 있는 기능을 미리 닫을 이유는 없다.

## 감수할 것
- 나중에 넣을 때 개인정보 처리 방침 문서가 필요하다.
