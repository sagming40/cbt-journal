# mockups — 화면 목업

[DESIGN.md](../DESIGN.md)의 결정을 그림으로 보여 주는 참고 자료다. 규격 · 색 결정의 단일 출처는 DESIGN.md다.
**로컬 파일로만 둔다.** claude.ai 캔버스 · Artifact에 올리지 않는다 (DESIGN 9장).

## 보는 방법
- `shared.js` · `shared.css`를 같은 폴더에서 불러오므로 **로컬 웹 서버로** 연다. 더블클릭(`file://`)으로 열면 브라우저에 따라 공용 파일을 못 불러온다.
  - 예: 이 폴더에서 `python -m http.server 5199` (conda 환경이 켜진 터미널) 또는 `npx http-server -p 5199` (http-server를 npm 캐시에 임시로 받는다. 프로젝트에는 아무것도 안 생긴다)
- 화면 위 도구 막대로 **시안(A ~ D) · 다크**를 바꿔 본다. 주소에도 남는다: `Checkin.mobile.html?palette=B&dark=1`
- 칩 · 슬라이더 · 단계 전환은 실제로 눌러 볼 수 있다.

입력칸 · 버튼 테두리는 장식 테두리(`border`, 1.3:1)가 아니라 `input`(3:1 이상)을 쓴다.

## 스타일 시안 (2026-11-01, 검토 중)
지금 목업 · 앱이 shadcn 기본 모양 그대로라 밋밋해서(사용자 의견), 다른 프로젝트 목업(PlayLedger · 자재 사전 — 어두운 바탕 · 큰 굵은 제목 · 벤토 카드 · 알약 메뉴)을 참고해 방향 셋을 그렸다. 색 규칙(6장 — 남색 하나, 빨강 · 주황 · 초록 없음, 강도는 명도)은 셋 다 그대로 지킨다. `Style.html`은 혼자 서는 파일이라 `shared.js`를 안 쓴다(B는 명조 글꼴 고운바탕을 Google Fonts에서 불러온다 — 목업만).
