# 요구사항: CBT 연습 도구

> **무엇을 만들고, 무엇을 만들지 않는지** 적는 문서다. 잘 바뀌지 않는다.
> 어떤 순서로 만드는지는 [PLAN.md](PLAN.md), 왜 이 스택인지는 [decisions/](decisions/README.md)에 있다.

## 1. 배경과 목표
- 인지행동치료(CBT)의 **사고 기록지(Thought Record)** 를 매일 쓰기 쉽게 만든 웹앱이다. 부정적 자동 사고를 알아채고, 근거를 따져 보고, 더 균형 잡힌 생각으로 바꾸는 연습을 돕는다.
- v1은 "가끔 길게 쓰는 일기장"이었다. v2는 **매일 짧게 들어와 연습하는 도구**다: 10초짜리 감정 체크인으로 습관을 만들고, 감정이 크게 흔들린 날은 사고 기록지를 쓴다 ([decisions/0001](decisions/0001-rewrite-v2.md)).
- 취미 프로젝트지만 "제대로" 만든다: 테스트, 마이그레이션, 보안, 개인정보 보호를 처음부터 갖춘다.
- 이 앱은 **치료를 대체하지 않는다.** 자기 관찰 · 연습 도구다.

## 2. 사용자와 운영 방식
| 구분 | 내용 |
|---|---|
| 지금 | 개발자 본인 혼자 쓴다. 회원가입은 설정(`ALLOW_SIGNUP=false`)으로 막혀 있다 |
| 나중 | 다른 사람에게 연다(가입 허용 또는 초대). 이때 5.3절 "공개 전 필수"를 먼저 갖춘다 |
| 설계 기준 | 처음부터 **다중 사용자**. 모든 사용자 데이터는 소유자가 있고, 남의 데이터는 "없는 것"과 똑같이 응답한다(404) |

## 3. 용어
| 용어 | 뜻 |
|---|---|
| 체크인 | 지금 감정과 강도만 빠르게 남기는 짧은 기록 |
| 사고 기록 | 아래 7칸을 채우는 긴 기록. 이 앱의 핵심 |
| 자동 사고 | 상황에서 즉각 떠오른 생각 (보통 부정적) |
| 인지 왜곡 | 자동 사고에 섞인 생각의 오류 패턴 (흑백논리, 파국화 등) |
| 근거 / 반대 근거 | 자동 사고를 뒷받침하는 사실 / 반박하는 사실 |
| 대안 사고 | 근거를 따져 본 뒤의 균형 잡힌 생각 |
| 강도 | 감정의 세기. **0 ~ 100** (v1의 1 ~ 10에서 바꿈 — 표준 사고 기록지 척도) |

## 5. 품질 요구 (기능은 아니지만 지켜야 하는 것)

### 5.1 개인정보
- 서드파티 분석 · 추적 스크립트를 넣지 않는다.
- **로그에 기록 내용(상황 · 생각 · 메모)을 남기지 않는다.** 로그에는 id · 요청 경로 · 결과 코드 정도만.
- 탈퇴하면 그 사용자의 모든 행을 즉시 지운다(Postgres CASCADE + Valkey 키 정리).
- 기록 내용은 외부로 나가지 않는다. 예외는 사용자가 켠 AI 코치(X1)뿐.
- **필드 단위 암호화는 하지 않는다.** 기록을 앱에서 암호화해 저장하면 통계 집계 · 검색이 크게 어려워진다. 대신 서버 접근 통제 · DB 포트 차단 · 백업 파일 암호화로 보호한다. 공개 시점에 다시 판단한다.
- 백업 파일을 서버 밖에 둘 때는 암호화한다.

### 5.2 보안
- 비밀번호는 argon2id 해시. 세션 쿠키는 `HttpOnly` · `Secure` · `SameSite=Lax`.
- 로그인 시도 · 가입 요청 횟수 제한. 기준 IP는 리버스 프록시 뒤에서도 실제 접속 IP다(ARCHITECTURE 3.3절).
- 없는 이메일로 로그인해도 응답 문구 · 걸리는 시간이 같다(가입 여부를 드러내지 않게).
- 쓰기 요청은 교차 출처 요청을 막는다(`http.CrossOriginProtection`).
- 모든 조회는 소유자 범위 안에서만. 남의 기록은 404.

### 5.3 공개 전 필수 (혼자 쓰는 동안은 보류)
- 위기 상황 안내(자살예방상담전화 109 등)와 "치료를 대체하지 않음" 고지를 화면에 둔다.
- 개인정보 처리 방침 페이지.
- A5(탈퇴) · A6(내보내기) 완료.
- 이메일로 비밀번호 재설정 (A9의 공개판. 메일 발송 수단이 필요하다).

### 5.4 사용성 · 기타
- **붙잡기는 휴대폰, 정리는 어디서든.** 생각이 떠오른 순간에 적는 것(체크인, 사고 기록 1 ~ 3단계)은 휴대폰 우선으로 설계한다. 차분히 따져 보는 것(사고 기록 4 ~ 8단계, 통계)은 PC와 휴대폰 둘 다 1급으로 다룬다. 기기를 옮겨 이어 쓰는 건 초안 자동저장(T3)으로 된다.
- 다크 모드 지원.
- 감정을 다루는 앱이라 **경고성 색(빨강 등)으로 감정 · 강도를 표시하지 않는다**(자세한 색 규칙은 DESIGN.md).
- 시각은 UTC로 저장하고, 화면 표시와 "하루" 경계는 사용자 시간대 기준.
- 한국어만 지원한다.

## 6. 하지 않을 것
- 기록 공유 · 소셜 기능 (다른 사용자와 기록을 보여 주는 모든 것)
- 상담사 · 치료사 연동, 진단 · 점수 판정
- 네이티브 앱 (PWA로 대신한다)
- 결제 · 유료 기능
- 다국어
